# Workspace Guidelines & Instructions

## User Prompts Logging
Whenever the user submits a new prompt in this project, record it in `USER_PROMPTS.txt` at the root of the project:
1. Append the new user prompt as `PROMPT #XXX` with:
   - Local timestamp (Asia/Karachi PKT)
   - UTC timestamp
   - Session ID
   - Full exact user prompt text
2. Keep the header counters updated (`Total Prompts Logged`, `Latest Prompt Date`, `File Last Updated`).
3. Ensure file has Windows CRLF (`\r\n`) line endings so it displays properly in Notepad.
